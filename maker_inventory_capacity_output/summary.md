# GALA locked-maker capacity curve

- Same frozen strategy as locked replay and fresh OOS: 10ms symmetric BBO, min spread 4.25bp, inventory cap = one order.
- Only order notional changes: $100 / $250 / $500 / $1000. This is capacity sensitivity, not a signal-parameter search.
- Three independent GALA captures are replayed; full displayed queue + own size must trade through; any touch change loses queue progress.
- Maker 2bp/fill; residual inventory taker-flattened at 5bp.
